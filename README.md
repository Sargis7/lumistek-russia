# Сайт Lumistek (Россия)

Одностраничный сайт компании Lumistek — премиальная полиуретановая защитная плёнка (PPF) для автомобилей.

Это обычный статический сайт: набор файлов, которые открываются в браузере. Никаких сборщиков, установок и программ на компьютере не нужно — всё меняется прямо на GitHub через браузер.

---

## Что где лежит

```
lumistek-russia/
├── index.html          ← сама страница (тексты, разметка)
├── news.json           ← список видео для блока «Новости» (обновляется сам)
├── assets/
│   ├── js/
│   │   ├── config.js   ← ЕДИНСТВЕННЫЙ файл настроек
│   │   └── news.js     ← логика новостного блока (не трогать)
│   └── video/          ← пустая папка, запасное место под видео
├── scripts/
│   └── fetch-news.mjs  ← скрипт обновления новостей (не трогать)
├── .github/workflows/
│   └── update-news.yml ← автоматическое обновление раз в сутки
├── logo.png            ← логотип
├── bg-video.mp4        ← видео на стартовом экране
├── product-1.jpg … product-10.jpg   ← фото товаров каталога
├── gallery-1.jpg … gallery-5.jpg    ← фото работ партнёров
├── .nojekyll           ← служебный, нужен для GitHub Pages
└── .gitignore          ← служебный, список мусорных файлов
```

**Важно про картинки и видео.** Все изображения и видео лежат прямо в корневой папке проекта, рядом с `index.html`, а не в `assets/img`. Так было в оригинальном сайте, и адреса в `index.html` (`logo.png?v=2`, `bg-video.mp4`, `product-1.jpg` и т.д.) менять не нужно. Просто загружайте файлы с ровно такими же именами — они сразу подхватятся.

Если картинку не заменить, на её месте будет «битая» иконка. Поэтому при первом запуске загрузите все файлы из списка выше.

## Как загрузить файлы на GitHub (без программ)

1. Зайдите на `github.com` под своим аккаунтом.
2. Откройте репозиторий сайта.
3. Нажмите **Add file → Upload files**.
4. Перетащите файлы в окно браузера (или нажмите «choose your files»).
5. Внизу страницы — кнопка **Commit changes**.
6. Подождите 1–2 минуты — сайт обновится сам.

### Если файл с таким именем уже есть

GitHub перезапишет его новым. Старая версия останется в истории, её можно вернуть.

### Как вернуть старую версию файла

Откройте файл → кнопка **History** (справа сверху) → выберите старый вариант → **Revert** или скопируйте текст вручную.

## 1. Как заменить фото

### Логотип — `logo.png`

- Формат: PNG с прозрачным фоном.
- Размер: ширина примерно 400–600 пикселей, высота подстраивается сама.
- Вес: до 100 КБ.
- Лучше горизонтальный вариант (знак + надпись), потому что в шапке он показывается в одну строку.

### Фото товаров — `product-1.jpg` … `product-10.jpg`

Каждый номер соответствует своему товару в каталоге:

| Файл | Товар |
|---|---|
| `product-1.jpg` | Lumistek Clear PPF |
| `product-2.jpg` | Lumistek WINDSHIELD PROTECTION |
| `product-3.jpg` | Lumistek CLEAR PRO |
| `product-4.jpg` | Lumistek MATE PROTECTION |
| `product-5.jpg` | Lumistek CLEAR ULTRA PRO |
| `product-6.jpg` | Lumistek ULTRA PRO ONE |
| `product-7.jpg` | Lumistek MHP PLUS 5 |
| `product-8.jpg` | Lumistek MHP PLUS 15 |
| `product-9.jpg` | Lumistek MHP PLUS 35 |
| `product-10.jpg` | Lumistek HEAD LIGHTS PROTECT |

- Размер: 1200 × 1200 пикселей (квадрат).
- Вес: до 300 КБ на файл.
- Фон: тёмный. Подложка карточки тёмная (`#0a0a0a`), поэтому фото на белом фоне будет выглядеть как белый прямоугольник.
- Фото показывается целиком, без обрезки, поэтому оставляйте немного воздуха по краям.

### Фото работ — `gallery-1.jpg` … `gallery-5.jpg`

- Размер: 1000 × 1250 пикселей (пропорция 4:5, вертикальные).
- Вес: до 400 КБ на файл.
- Фото заполняет карточку целиком и **обрезается по краям**. Главное держите по центру.

### Как сжать фото

Проще всего — сайт `squoosh.app` (бесплатный, работает в браузере, ничего ставить не надо):

1. Откройте `squoosh.app`.
2. Перетащите фото.
3. Справа выберите **MozJPEG**, качество **75–80**.
4. Если вес всё ещё большой — уменьшите размер в блоке **Resize**.
5. Нажмите стрелку загрузки внизу справа.
6. Назовите файл точно как в таблице (`product-3.jpg` и т.д.).

## 2. Как заменить видео на стартовом экране

Файл: `bg-video.mp4` (имя менять не нужно).

**Требования:**

- Формат: MP4 с кодеком H.264 — это стандарт, поддерживается везде.
- Разрешение: 1920 × 1080 (Full HD) — оптимум.
- Вес: **до 10–15 МБ**. Больше — сайт будет грузиться долго, особенно с мобильного интернета.
- Звук: можно оставить, но он всё равно не играет — видео принудительно беззвучное (так требуют браузеры, иначе автозапуск запрещён).
- Длительность: 10–30 секунд, видео зацикливается само.

**Как сжать видео:**

1. Откройте `freeconvert.com/video-compressor` или `cloudconvert.com`.
2. Загрузите видео.
3. Настройки: MP4, H.264, качество «High» или «Medium».
4. Если файл всё равно больше 15 МБ — выберите «Target size» / «Compress to size» и укажите 10 МБ.
5. Скачайте, переименуйте в `bg-video.mp4` и загрузите на GitHub.

**Совет по содержимому:** тёмный ролик с медленным движением камеры смотрится лучше всего — поверх него лежит затемнение 60% и белый текст.

### Заставка, пока видео грузится

Пока `bg-video.mp4` не готов, за стартовый экран отвечает картинка-заставка `hero-poster.jpg` из корня проекта. Она видна первую секунду-две, пока подгружается видео, и на медленном мобильном интернете.

Заменить её можно двумя способами:

1. **Ничего не делать.** Если файла нет, стартовый экран остаётся чёрным — это тоже аккуратный вариант, поскольку поверх всё равно лежит затемнение.
2. **Положить свой кадр.** Возьмите любой кадр из ролика (или сделайте скриншот), сохраните как JPEG шириной 1920 px и назовите ровно `hero-poster.jpg`. Он встанет на место автоматически.

Если хотите **убрать** заставку совсем — удалите атрибут `poster="hero-poster.jpg"` в строке с `<video>` (около 149-й строки `index.html`).

## 3. Как добавить или убрать новости YouTube

Блок «Новости Lumistek» находится между каталогом и разделом «Наши работы». Карточки в нём — вертикальные превью видео, как в YouTube Shorts. По клику открывается окно с плеером.

### Как это устроено (коротко)

Список видео лежит в файле **`news.json`** в корне сайта. Этот файл **обновляется автоматически раз в сутки** силами GitHub — вам обычно ничего делать не нужно.

1. Вы выкладываете новое видео на YouTube.
2. Ночью (около 6 утра по Москве) GitHub сам забирает его и вписывает в `news.json`.
3. Утром видео уже на сайте.

Пока `news.json` загружается, на экране сразу видны карточки из резервного списка в `config.js` — поэтому блок никогда не выглядит пустым.

**Почему в блоке нет задержки в несколько секунд.** `news.json` лежит на вашем же сайте, поэтому браузер забирает его мгновенно. Раньше сайт ходил за видео напрямую на YouTube — это занимало 1–4 секунды, и карточки успевали «мигнуть». Теперь этого нет.

**Про запасной путь «в реальном времени».** В `config.js` есть настройка `liveRefresh`. Если поставить `true`, сайт при загрузке дополнительно сходит на YouTube через сторонний сервис — но только если `news.json` старше суток. По умолчанию выключено: суточного обновления достаточно, а лишний запрос замедляет страницу. Учтите два момента, если решите включить: такие сервисы кэшируют ответ примерно на 5 минут (только что выложенное видео может не появиться сразу), и при наплыве посетителей они отвечают отказом — тогда сайт просто остаётся на данных из `news.json`.

### Обновить прямо сейчас, не дожидаясь ночи

1. Откройте репозиторий → вкладка **Actions**.
2. Слева выберите **Update news**.
3. Справа кнопка **Run workflow** → ещё раз **Run workflow**.
4. Подождите минуту, обновите страницу сайта.

Кнопка видна только если в репозитории уже есть файл `.github/workflows/update-news.yml` — он в проекте лежит.

### Сколько видео показывать

В `assets/js/config.js`:

```js
maxVideos: 8,
```

Поставьте от 1 до 15. YouTube отдаёт максимум 15 видео.

### Показывать только вертикальные ролики

```js
shortsOnly: true,
```

- `true` — в блоке только вертикальные Shorts. Обычные горизонтальные видео будут видны с чёрными полосами, поэтому они скрываются.
- `false` — показывать всё, включая горизонтальные.

### Добавить видео вручную

Нужно, если автоматика не сработала или хочется поставить видео в начало.

Откройте `assets/js/config.js`, найдите `fallbackShorts` и вставьте блок сверху списка:

```js
fallbackShorts: [
    {
        id: 'CSKxV0giqUk',
        title: 'Заявка на сотрудничество на сайте Lumistek',
        date: '2026-08-12'
    },
    // ... остальные
],
```

- **`id`** — код видео, 11 символов (как его взять — ниже).
- **`title`** — подпись на карточке, до ~60 символов.
- **`date`** — `'год-месяц-день'`, например `'2026-08-12'`. На сайте покажется «12 августа 2026».

**Чтобы убрать видео** — удалите его блок целиком, вместе со скобками `{ }` и запятой.

### Как узнать ID видео из ссылки YouTube

- `youtube.com/shorts/CSKxV0giqUk` → ID это **`CSKxV0giqUk`**
- `youtube.com/watch?v=LU06gyGyM08` → ID это **`LU06gyGyM08`**
- `youtu.be/D3lxuHnN4Wk` → ID это **`D3lxuHnN4Wk`**

Это всегда 11 символов после `/shorts/`, после `v=` или после `youtu.be/`. Ссылку целиком вставлять не нужно.

### Можно править news.json руками

Файл простой: сверху дата обновления, ниже список видео. Технически можно вписать туда видео вручную — но при следующем ночном обновлении GitHub перезапишет файл. Поэтому ручные правки лучше делать в `fallbackShorts`, а не в `news.json`.

### Три правила, чтобы ничего не сломать

1. Не удаляйте скобки `{ } [ ]` и запятые между блоками.
2. Весь текст — в кавычках: `'вот так'`.
3. Если внутри подписи нужна кавычка — используйте двойную `"`.

Если сломали — GitHub → **History** → старая версия → **Revert**.

## 4. Как поменять телефоны, адреса и цены

Всё это в файле `index.html`. Нажмите на него на GitHub, потом на карандаш (Edit) справа сверху. После правки — **Commit changes**.

Не пугайтесь разметки. Нужные места легко найти поиском: нажмите `Ctrl+F` в браузере (на Mac — `Cmd+F`).

### Телефоны

Номер встречается в двух местах, и оба надо поменять — иначе клик по номеру на телефоне не сработает.

1. Видимая часть, её читает человек:
   ```
   +7 (991) 718-44-42
   ```
2. Часть внутри `href`, по ней звонит телефон — без пробелов, скобок и дефисов:
   ```
   href="tel:+79917184442"
   ```

Ищите по числу, например `991` — браузер подсветит все вхождения. В шапке, в подвале и в каждом филиале свой номер.

### Адреса филиалов

Ищите название города: `Москва`, `Уфа`, `Самара`, `Ереван`. Рядом будет адрес:

```html
<p class="text-gray-400 text-sm mb-3">Видное, Белокаменное шоссе 20<br>БЦ Видный</p>
```

`<br>` — перенос строки. Если строк стало меньше или больше, добавьте или уберите `<br>`.

### Цены

Цены в каталоге выглядят так:

```html
<p class="text-brand-cyan font-semibold text-xs md:text-sm uppercase tracking-wider">Цена за рулон (1.52х15м): 104 990₽</p>
```

Меняйте только текст после двоеточия. Где сейчас `По запросу` — так и останется, пока не впишете цену.

### Тексты и заголовки

Любой обычный текст между тегами можно менять: `<h2>Каталог Lumistek</h2>` → `<h2>Наш каталог</h2>`.

Главное — **не трогайте то, что внутри `class="..."`** и не удаляйте угловые скобки `< >`. Это разметка оформления, её поломка испортит вид страницы.

## 5. Как выложить сайт на GitHub Pages

Делается один раз.

1. Откройте репозиторий сайта на GitHub.
2. Вкладка **Settings** (шестерёнка вверху справа).
3. В левом меню — **Pages**.
4. В блоке **Build and deployment**:
   - **Source**: выберите `Deploy from a branch`;
   - **Branch**: выберите `main`, папку — `/ (root)`;
   - нажмите **Save**.
5. Подождите 1–3 минуты. Обновите страницу — сверху появится адрес вида `https://имя-аккаунта.github.io/имя-репозитория/`.

Дальше сайт обновляется автоматически после каждого **Commit changes** — больше ничего нажимать не нужно.

### Разрешить GitHub Actions записывать файлы

Нужно один раз, иначе автообновление новостей не сможет сохранить `news.json`.

1. **Settings** → **Actions** → **General**.
2. Прокрутите до раздела **Workflow permissions**.
3. Выберите **Read and write permissions**.
4. Нажмите **Save**.

Файл `.github/workflows/update-news.yml` уже содержит `permissions: contents: write`, но при некоторых настройках репозитория этого недостаточно — тогда поможет пункт выше.

### Свой домен (например, lumistek.ru)

Всё там же, в **Settings → Pages**, поле **Custom domain**: впишите домен и нажмите **Save**. На стороне регистратора домена нужно добавить CNAME-запись на `имя-аккаунта.github.io` — обычно это делает подрядчик, который ведёт ваш домен.

### Файл `.nojekyll`

Он уже есть в проекте, удалять его нельзя. Без него GitHub Pages может не отдать часть файлов и сломать сайт.

## 6. Что делать, если блок новостей не грузится

Ситуаций может быть две — проверяйте по порядку.

### Случай 1. Карточки показываются, но видео в них старое

Это значит, что не сработало автоматическое обновление, и сайт показывает резервный список из `config.js`.

**Проверьте, работает ли автоматика:**

1. Вкладка **Actions** в репозитории.
2. Слева — **Update news**. Виден ли там зелёный значок у последнего запуска?
   - **Красный крестик** — откройте его и посмотрите текст ошибки. Чаще всего это временный сбой: просто нажмите **Run workflow** ещё раз.
   - **Запусков нет вообще** — проверьте, что файл `.github/workflows/update-news.yml` есть в репозитории.

**Быстрое решение без выяснения причин:** добавьте видео вручную в `fallbackShorts` в `config.js` — раздел 3 этой инструкции. Так блок будет работать всегда, независимо от автоматики.

### Случай 2. Блок пустой или его вообще нет на странице

Проверьте по порядку:

1. **Открыт ли `news.json`.** Введите в адресной строке браузера адрес сайта + `/news.json`. Должен открыться текст с датой и списком видео. Если 404 — файл не загружен в репозиторий. Возьмите его из проекта и загрузите на GitHub в корень.
2. **Заполнен ли `fallbackShorts`.** Если в `config.js` этот список пуст, а `news.json` недоступен, блок честно скрывается, чтобы не оставалась пустая полоса. Добавьте хотя бы пару видео.
3. **Не сломаны ли скобки в `config.js`.** Если после правки пропала запятая или скобка, весь файл настроек перестанет работать. Сравните с прошлой версией через **History**.

### Видео не воспроизводится при нажатии на карточку

Превью-картинки показываются, а после клика чёрное окно или ошибка. Причины две:

- **YouTube недоступен у посетителя.** Плеер встроить без YouTube нельзя — это ограничение самого сервиса, обойти его в коде сайта невозможно. Так бывает с части посетителей из России без VPN.
- **Страница открыта как локальный файл.** Если открыть `index.html` двойным щелчком с рабочего стола, YouTube отказывается запускать плеер (ошибка 153). Страница должна быть открыта по обычному адресу — с GitHub Pages или с локального сервера.

### Про запасной путь через сторонний сервис

В `config.js` есть настройка `liveRefresh: false`. Если поставить `true`, сайт будет дополнительно пытаться забрать видео с YouTube через сторонний публичный сервис, когда `news.json` старше суток.

По умолчанию она **выключена** — так правильнее. Этот путь медленный (1–4 секунды), бесплатный сервис может не ответить, и тогда карточки на экране перерисуются без видимой причины. Основное обновление и так делает GitHub раз в сутки. Включайте только если очень нужна свежесть в реальном времени.

## Мелкие вопросы

**Где поменять год в подвале?** Поищите `© 2024` в `index.html`.

**Где поменять текст политики конфиденциальности?** Поищите `Политика конфиденциальности определяет` в `index.html` — это ближе к концу файла, в модальном окне.

**Форма заявки работает в тестовом режиме.** Она показывает «Заявка отправлена», но никуда не отправляется. Для реальной отправки нужен Telegram-бот: в `index.html` найдите комментарий `НАСТРОЙКА TELEGRAM БОТА`, впишите свои `botToken` и `chatId`, затем раскомментируйте блок с `fetch(...)` чуть ниже — уберите `/*` перед ним и `*/` после.

Токен бота — это секрет. Если положите его прямо в `index.html` в открытом репозитории, его сможет увидеть любой. Для боевого сайта лучше вынести отправку на отдельный сервис (например, форму Google или серверную функцию), а не хранить токен в коде страницы.

**Почему карточки в каталоге листаются не как раньше?** Не менялось — механизм тот же, что был. На телефоне — свайп, на компьютере — стрелки по бокам и точки внизу.

**Новости не появились в меню.** Пункт «Новости» добавлен между «Каталогом» и «Нашими работами» и на компьютере, и в мобильном меню. Если не видно — обновите страницу с зажатым Shift (жёсткое обновление, сбрасывает кэш).

**Можно ли обновлять новости без GitHub Actions?** Да. Если автоматика мешает или кажется сложной — впишите видео вручную в `fallbackShorts` в `config.js` (раздел 3). В этом случае `news.json` и папку `.github/` можно не трогать: сайт будет просто показывать ваш список. Ничего не сломается.
